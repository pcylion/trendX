    Responsible use

    Headlines come from Google News, Bing News and GDELT, so they can occasionally fail or lag. Check facts before you post. This app only writes text. The Post on X button opens X with the text filled in, and you press Post yourself. For replies, the comment is copied and the post opens so you can paste it into the reply box. Automated mass posting can break X's rules and get accounts limited. Critical and negative lines stay on opinions about the game and the claims, with no insults, threats or false accusations, and they are not meant to be posted in bulk at one person.

    Install: on Android tap Install above. On iPhone use Share, then Add to Home Screen.
